IFC Bloat AnalyzerA fast, lightweight Python application designed to analyze Industry Foundation Classes (.IFC) files. It determines content composition, identifies "heavy" geometry, and spots potential data bloat without the need for slow 3D rendering.FeaturesComposition Breakdown: Calculates the percentage of file size/count dedicated to Geometry, Metadata, Relationships, and Core definitions.Heavy Object Detection: Identifying specific objects (e.g., furniture, detailed hardware) that contain disproportionately high polygon or face counts using a smart "bottom-up" density check.Header Analysis: extracts detailed information from the IFC header (Originating System, View Definition, Timestamp, Author).Bloat Statistics: Lists the top 5 most common entities to spot excessive tessellation or property set duplication.Orphan Check: detailed sampling to estimate how many entities in the file are unreferenced "dead weight" (orphaned data).GUI: Clean interface built with Tkinter.PrerequisitesPython 3.x installed on your system.The ifcopenshell library.InstallationClone or download this repository.Ensure you have the required image file Romblad_Haxx.png in the same directory as the script.Install the required dependencies:python -m pip install ifcopenshell
(Note: tkinter is usually included with standard Python installations).UsageRun the script directly via Python:python ifc_analyzer.py
Click "Select .IFC File".Wait for the analysis to complete (large files may take a few seconds).Review the generated log for insights.Building a Standalone Executable (.exe)To create a single file application that you can share with others (who don't have Python installed), use PyInstaller.1. Install PyInstallerpython -m pip install pyinstaller
2. Build CommandRun the following command exactly as written. It handles the inclusion of the logo image and forces the collection of the complex ifcopenshell dependencies:python -m PyInstaller --noconsole --onefile --collect-all ifcopenshell --add-data "Romblad_Haxx.png;." --name "IFC Analyzer" ifc_analyzer.py
Breakdown of flags:--noconsole: Hides the command prompt window.--onefile: Bundles everything into a single .exe.--collect-all ifcopenshell: Critical. Ensures all hidden schema files required by the IFC library are included.--add-data "Romblad_Haxx.png;.": Bundles the logo image into the root of the executable.3. Locate the AppAfter the build finishes, find your standalone application in the dist folder.Troubleshooting"Pip is not recognized": If you get errors trying to install libraries, ensure Python is added to your system PATH, or use py -m pip ... on Windows."Missing Library" inside the App: If the app runs but complains about missing libraries, click the "Attempt Auto-Install" button in the UI, or manually run the installation command provided in the terminal.Image not showing: Ensure Romblad_Haxx.png is in the same folder as the script when running from source.
